# 🌍 FluentGO — Tradutor Inteligente

FluentGO é um tradutor online moderno que permite traduzir textos para vários idiomas e também usar reconhecimento de voz 🎤.  
O projeto foi desenvolvido com foco em simplicidade, usabilidade e aprendizado prático de APIs e JavaScript.

---

## 🚀 Funcionalidades

- ✅ Tradução de texto em tempo real
- 🌎 Suporte a múltiplos idiomas:
  - Português
  - Inglês
  - Alemão
  - Francês
  - Espanhol
  - Japonês
  - Mandarim
  - Russo
  - Hindi
- 🎤 Reconhecimento de voz (microfone)
- 💡 Feedback visual de tradução
- 🎨 Interface moderna e responsiva

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3

- Web Speech API (Reconhecimento de Voz)

---

## 📌 Como Usar

1. Digite um texto no campo de entrada
2. Escolha o idioma de destino
3. Clique no botão de tradução ou use o microfone 🎤
4. Veja o resultado traduzido na tela

---

## 💡 Objetivo do Projeto

O FluentGO foi criado como um projeto de aprendizado para praticar:

- Consumo de APIs REST
- Manipulação do DOM
- Async/Await e Fetch
- Integração com reconhecimento de voz
- Versionamento com Git e GitHub
- Organização de código front-end
